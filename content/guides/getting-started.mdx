## Platform Shape

Mirage is organized as a Next.js App Router product shell. Public pages live in `src/app`, authenticated workspace routes sit behind role-aware groups, and server routes are grouped under `src/app/(backend)/api`.

## Content Strategy

Use guides for platform-specific implementation material: setup paths, account workflows, API usage, admin operations, and feature playbooks. Guides can be nested as the platform grows.
